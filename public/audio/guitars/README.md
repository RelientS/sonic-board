# Sonic Board guitar samples

These browser-ready PCM WAV files are trimmed from a CC0 1.0 raw DI multi-sample instrument. Filenames identify the recorded root note; Sonic Board selects the nearest sample and pitch-shifts it for each performance event.

## Sources

- `fender-direct-soft/`, `fender-direct-balanced/`, `fender-direct-picked/`, and `fender-direct-dark/`: FreePats FSBS Electric Guitar Direct, bridge pickup, release 2022-09-11. Source: https://freepats.zenvoid.org/ElectricGuitar/clean-electric-guitar.html — CC0 1.0.

The source files are direct recordings of the guitar's raw signal with no amplifier or effects rack. Sonic Board uses soft and regular takes plus gentle low-pass voicing; distortion and amplification are added only by the user's selected pedal and amp chain.
