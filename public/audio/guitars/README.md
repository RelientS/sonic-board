# Sonic Board guitar samples

These browser-ready AAC files are trimmed and transcoded from CC0 1.0 multi-sample instruments. Filenames identify the recorded root note; Sonic Board selects the nearest sample and pitch-shifts it for each performance event.

## Sources

- `fender-clean/` and `fender-jazz/`: FreePats Clean Electric Guitar small SFZ+FLAC banks, bridge pickup Clean and Jazz variants, release 2026-08-07. Source: https://freepats.zenvoid.org/ElectricGuitar/clean-electric-guitar.html — CC0 1.0.
- `gretsch/`: the green Gretsch Anniversary from Black & Green Guitars. Source: https://github.com/sfzinstruments/karoryfer.black-and-green-guitars — CC0 1.0.
- `hofner/`: the black Hofner Club from Black & Green Guitars. Source: https://github.com/sfzinstruments/karoryfer.black-and-green-guitars — CC0 1.0.

The original libraries contain more articulations and velocity layers. Sonic Board currently uses one medium-velocity ordinary articulation per root note to keep the public demo lightweight.
